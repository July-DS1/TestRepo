# Predictive Maintenance Analysis using Python

## Project Overview
This project analyzes machine operating data to understand failure patterns and predict equipment failure using machine learning.

## Objectives
- Analyze machine performance data
- Identify key factors affecting machine failure
- Build a predictive model for failure detection

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
Predictive Maintenance Dataset (10,000 records of machine data)

## Exploratory Data Analysis
- Failure distribution analysis
- Torque vs failure relationship
- Tool wear analysis
- Correlation analysis

## Key Insights
- Most machines operate without failure
- Tool wear significantly increases failure probability
- High torque is a major risk factor
- Predictive maintenance can reduce downtime

## Machine Learning Model
- Model: Random Forest Classifier
- Accuracy: ~98%
- Features used:
  - Air temperature
  - Process temperature
  - Rotational speed
  - Torque
  - Tool wear
